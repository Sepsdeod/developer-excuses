One funny single-line excuse a developer gives when code breaks in production,
written for make.fun's
[Make the AI Judge Laugh: Developer Excuses](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3)
bounty. A judge model compares the lines head to head; the line that lands
the biggest laugh wins.

## How to run

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt` (UTF-8, one line, under
200 characters) and asserts the length gate before writing.
